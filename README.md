# suyash.live

Official website of **Suyash Goswami** — independent artist, vocalist and acoustic musician from Indore.

Static single-page site (`index.html` + `media/`). No build step: open `index.html` or serve the folder.

- Hosting: GitHub Pages (branch `main`, root)
- Custom domain: add a `CNAME` file containing `suyash.live` once the domain's DNS points to GitHub Pages
- Booking form composes an enquiry for Instagram DM / email (`hello@suyash.live` — set up this inbox)
